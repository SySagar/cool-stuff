## 🎯 Philosophy

**Learn → Build → Break → Understand.**

Most experiments start with a question like:

> *"What actually happens under the hood?"*

Then I build a small implementation or simulation to find out.

This repo is basically my **CS engineering playground**. 🛠️

## 📚 Topics

`Operating Systems` · `Networking` · `Databases` · `Concurrency` · `Distributed Systems` · `Browser Internals` · `Backend Engineering`
